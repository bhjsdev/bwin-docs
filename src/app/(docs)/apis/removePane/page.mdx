# `removePane`

## Description

Remove a pane from the window.

```js
binaryWindow.removePane(sashId);
```

## Parameters

| Name     | Type   | Description                       |
| -------- | ------ | --------------------------------- |
| `sashId` | string | Sash ID of the pane to be removed |

## Returns

**Type**: `void`
