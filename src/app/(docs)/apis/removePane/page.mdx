# `removePane`

## Description

Remove a pane from the window, along with the
<a href={getPath('/general/glass')}>glass</a> it holds. The removed pane's sibling
expands to fill the freed space.

```js
binaryWindow.removePane(sashId);
```

## Parameters

| Name     | Type   | Description                       |
| -------- | ------ | --------------------------------- |
| `sashId` | string | Sash ID of the pane to be removed |

## Returns

**Type**: `void`
